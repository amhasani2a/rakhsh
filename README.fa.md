# 🐎 رخش · Rakhsh

**یک هستهٔ جستجو و تصمیم‌گیری «واکنشی» که با یک عبور رو به جلو (Single Forward) کار می‌کند و از داده‌ها و بازخوردهای *خودت* یاد می‌گیرد.**
فقط پایتون + NumPy · بدون GPU · بدون اینترنت · سرور MCP · ‏REST API · رابط چت وب

[English](README.md) · [دورهٔ آموزشی ۱۰ جلسه‌ای](docs/course/README.md) · [معماری](docs/ARCHITECTURE.md)

</div>

> در شاهنامه، وقتی رستم خواب بود شیری به او حمله کرد و **رخش** پیش از آنکه رستم بیدار شود شیر را کشت.
> این یعنی رفلکس: کار درست، در لحظه، بی‌آنکه «مغز کندِ فکرکننده» بیدار شود.
> این پروژه برای داده‌های تو یک رخش می‌سازد.

## ۱. رخش چیست؟

بیشتر سیستم‌های جستجوی هوش مصنوعی «عاملِ حلقه‌ای» هستند: برنامه بریز ← ابزار صدا بزن ← بخوان ← دوباره برنامه بریز… هر قدم یک
فراخوانی مدل بزرگ است و هزینه دارد. رخش برعکس است: **یک عبور از یک شبکهٔ کوچک** هم‌زمان سه چیز می‌دهد:

| سَر (Head) | خروجی | تشبیه |
|---|---|---|
| **متراکم (dense)** | بردار معنا ← جستجوی معنایی | «این دربارهٔ چیست؟» |
| **اسپایک‌های تُنُک (sparse)** | چند نورونِ واژه که شلیک می‌کنند، حتی واژه‌هایی که *ننوشتی* (گسترش پرسش) | «کدام کلیدواژه‌ها روشن می‌شوند؟» |
| **گیت هَزارد (hazard gate)** | احتمال توقف در هر عمق: `reflex ← spike ← deep` | «چقدر باید فکر کنم؟» |

و **بعد از نصب هم یاد می‌گیرد**: هر 👍 / 👎 / «همین یکی» سیناپس‌های سریعِ هبی و *نورون‌های رفلکسِ اپیزودیک* می‌سازد (سؤالِ تأییدشده
دفعهٔ بعد از حافظه جواب می‌گیرد — `path = reflex-arc` — بدون هیچ جستجویی). با `sleep()` تجربه‌ها در وزن‌های کند تثبیت می‌شوند.

پاسخ‌ها **استخراجی**‌اند: رخش از داده‌های خودت *نقل‌قول* می‌کند، همراه منبع و نشانی (فصل/بند، جدول/سطر). هیچ‌وقت متن از خودش نمی‌سازد.
برای همین مناسب است برای:

* **پایگاه دانش خصوصی** روی کتاب، یادداشت، CSV/Excel/SQLite/JSON، ‏PDF/Word/HTML؛
* **حافظه و ابزار بازیابی برای عامل‌های LLM** (Claude، Cursor، هر کلاینت MCP) — ارزان‌تر از یک فراخوانی دیگرِ LLM؛
* **لایهٔ تصمیم‌گیری کوچک** (`Decider`): مسیردهی پرامپت به «بدون LLM / مدل کوچک / مدل بزرگ»، اولویت‌بندی تیکت، تشخیص نیت —
  با چند مثال آموزش می‌بیند، در **کمتر از ۱ میلی‌ثانیه** تصمیم می‌گیرد و می‌گوید *کدام واژه‌ها* باعث تصمیم شدند.

## ۲. معماری

<div dir="ltr">

```
            ┌──────────────── adapters (thin, replaceable) ────────────────┐
            │  Web UI      REST /api/b/<brain>/<action>     MCP (stdio|HTTP) │   CLI   SDK
            └───────────────────────────────┬──────────────────────────────┘
                                            │  actor = "human" | "agent:<name>"  →  TrustPolicy
            ┌───────────────────────────────▼──────────────────────────────┐
            │ Registry   (brains/, deciders/, audit.jsonl, snapshots)        │
            │   Brain  ── ingest → chunk → self-supervised training           │
            │   Decider ── few-shot labels → prototypes + tiny net → decide   │
            └───────────────────────────────┬──────────────────────────────┘
            ┌───────────────────────────────▼──────────────────────────────┐
            │ core/  text · autograd · model(ReflexNet) · index · selfsup    │
            │        plasticity(Hebbian + episodic) · answer                 │
            └──────────────────────────────────────────────────────────────┘

query ─► featurise ─► trunk ─┬─► dense head ───────────────► cosine
                             ├─► spike head: log1p(ReLU) ──► prune ─► inverted index
                             └─► hazard gate ─► P(stop at 0,1,2) ─► K + fusion weights
```

</div>

* **هسته (`core/`)** فقط ریاضی است و هیچ I/O ندارد؛ حتی مشتق‌گیری خودکار (autograd) را خودمان نوشته‌ایم و با گرادیان عددی چک شده.
* **آداپتورها** نازک و قابل تعویض‌اند: رابط وب، REST، ‏MCP و CLI همگی همان `Registry` را صدا می‌زنند.
* **ذخیره‌سازی امن**: فقط JSON و NPZ (بدون pickle)؛ پس باز کردن مغزی که کسی برایت فرستاده نمی‌تواند کد اجرا کند.

جزئیات: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)

## ۴. شروع سریع

### ۴٫۱ رابط وب
<div dir="ltr">

```bash
rakhsh serve            # → http://127.0.0.1:8765
```

</div>

فایل را بکش و رها کن (کتاب، CSV، ‏SQLite، ‏Excel، ‏PDF، ‏Word، ‏HTML، ‏JSON) یا متن بچسبان ← مغز خودش آموزش می‌بیند ← گفتگو کن.
کنار هر پاسخ سطح گیت، اسپایک‌های شلیک‌کرده (نارنجی = واژه‌ای که ننوشتی)، اطمینان، زمان و دکمه‌های 👍 / 👎 / «همین یکی» دیده می‌شود.
از نوار کناری می‌توانی بین مغزها جابه‌جا شوی یا مغز تازه بسازی. دکمهٔ «بخواب» حافظه را تثبیت می‌کند.

### ۴٫۲ کتابخانهٔ پایتون (SDK)
<div dir="ltr">

```python
from rakhsh import Registry

reg = Registry("~/.rakhsh")
brain = reg.brain("cinema")
brain.ingest("cinema_book.txt", open("samples/cinema_book.txt", "rb").read())
brain.wait()                                   # آموزش خودنظارتی در پس‌زمینه

r = brain.ask("فیلمی دربارهٔ آلزایمر پدر و دادگاه")
print(r["answer"]["text"], r["answer"]["locator"], r["meta"]["level_name"])

brain.feedback(r["id"], "up")                  # 👍  دفعهٔ بعد: reflex-arc
brain.teach("پیشنهاد امشب چیه؟", answer="امشب «جدایی نادر از سیمین» را ببین.")
brain.save()
```

</div>

|---|---|

| `brain_ingest` | افزودن فایل (فقط داخل `--allow-dir`)، متن خام یا بایت base64 |
| `brain_status` | وضعیت آموزش، منابع، آمار یادگیری |
| `brain_ask` | پاسخ نقل‌قولی + منبع/نشانی + ردِ تصمیم + گزینه‌های دیگر + `message_id` |
| `brain_search` | فقط فهرست نتایج |
| `brain_probe` | فقط تصمیم: کدام اسپایک‌ها شلیک می‌کنند و گیت کدام سطح را انتخاب می‌کند |
| `brain_feedback` | ‏`up` / `down` / `pick` برای یک `message_id` |
| `brain_teach` | آموزش مستقیم «سؤال ← جواب» (اگر جواب در داده نباشد، دانش تازه اضافه می‌شود) |
| `brain_sleep` | تثبیت حافظهٔ اپیزودیک در وزن‌های کند |
| `brain_snapshot` | نسخه‌برداری از مغز |
| `brain_remove_source` | فراموش کردن یک منبع |
| `decider_create` / `decider_teach` / `decider_decide` | لایهٔ تصمیم‌گیری |

## ۵. لایهٔ تصمیم (`Decider`)

* دو حالت **دسته‌ای** (categorical) و **ترتیبی** (ordinal). در حالت ترتیبی، وقتی مطمئن نیست به گزینهٔ امن‌تر (بالاتر) *ارتقا* می‌دهد.
* حافظهٔ نمونه‌ای (prototype) که از *یک مثال برای هر برچسب* هم کار می‌کند، ترکیب‌شده با یک شبکهٔ کوچک که با دادهٔ بیشتر بهتر می‌شود.
* زیر آستانهٔ اطمینان `abstained=True` می‌دهد؛ یعنی «از انسان یا LLM بپرس و بعد `teach` کن».
* `evidence` نشان می‌دهد هر واژه چقدر در تصمیم سهم داشت (روش حذفِ تک‌تکِ واژه‌ها).

**معلم ← شاگرد:** یک LLM بزرگ فقط چند نمونه را یک‌بار برچسب می‌زند (با `decider_teach`) و بعد از آن رخش همهٔ تصمیم‌های آینده را محلی و
در چند میکروثانیه می‌گیرد. یعنی «تقطیر دانش» به‌شکل یک گردش‌کار.

## ۶. اعتماد، همکاری و امنیت

* هر فراخوانی یک **کنشگر** دارد: `human` (رابط وب/CLI/SDK) یا `agent:<name>` (نام کلاینت MCP یا هدر `X-Rakhsh-Actor`).
* `TrustPolicy`: انسان = ۱٫۰، عامل ناشناس = ۰٫۵، و برای هر عامل با `--trust name=0.8`.
  * قدرت بازخورد در اعتماد ضرب می‌شود؛
  * نورون رفلکس فقط وقتی شلیک می‌کند که **مجموع اعتماد ≥ ۱٫۰** شود (یک انسان، یا دو عامل ۰٫۸ که با هم موافق‌اند)؛
  * یادگیری کند (گرادیانی) فقط از کنشگرهای با اعتماد ≥ ۰٫۷۵؛ یک عامل «اسپم» با اعتماد ۰٫۱ نمی‌تواند مغز را بازنویسی کند.
* **دفتر رویداد** (`audit.jsonl`): چه کسی، کی، چه چیزی اضافه کرد یا یاد داد.
* **نسخه‌برداری**: با `snapshot` / `restore` یک جلسهٔ آموزشِ بد را برگردان.
* سرور فقط روی `127.0.0.1` باز می‌شود؛ برای شبکه `--token` لازم است؛ هدر `Origin` مرورگر چک می‌شود؛ دسترسی فایلِ MCP محدود به `--allow-dir` است.

## ۷. نتایج سنجش (صادقانه و کوچک)

مجموعهٔ پژوهشی: ۳۶ سند فیلم فارسی، ۱۰۸ پرسش آزمون در سه سطح دشواری (ناوبری / کلیدواژه / انتزاعی‌ـ‌بازنویسی‌شده). بازتولید: `rakhsh bench`.
اعداد بین اجراها حدود ±۰٫۰۲ تغییر می‌کنند.

| سیستم | R@1 | R@5 | MRR@10 | ‏R@1 پرسش‌های انتزاعی |
|---|---|---|---|---|
| ‏BM25 (پایهٔ کلاسیک) | 0.870 | 0.944 | 0.898 | 0.611 |
| رخش، فقط اسپایک | **0.917** | **0.963** | **0.936** | **0.750** |
| رخش، فقط متراکم | 0.898 | 0.954 | 0.921 | 0.722 |
| رخش، تطبیقی (با گیت) | 0.898 | 0.963 | 0.924 | 0.694 |

دقت گیت ۰٫۸۰ · میانگین K برابر ۴٫۷ · حدود ۱۷ اسپایک فعال از ~۶۲۰ · تأخیر میانه ۰٫۴۴ میلی‌ثانیه.
آزمون مقیاس (یک هستهٔ CPU): کتاب ~۲۵۰ هزار واژه‌ای در ~۹۵ ثانیه آموزش می‌بیند؛ هر پرسش ≈ ۳٫۵ میلی‌ثانیه؛ هر بازخورد ≈ ۱ ثانیه در پس‌زمینه.

**این نتایج چه چیزی را ثابت *نمی‌کنند*:** داده کوچک است و با مدل‌های بزرگِ ازپیش‌آموزش‌دیده مقایسه نشده (که احتمالاً در معنای عمومی بهترند).
ادعای ما محدودتر است: *یک مدل خیلی کوچک، خودآموز، توضیح‌پذیر و فقط‌CPU می‌تواند روی دادهٔ خودت از BM25 بهتر باشد و با بازخورد بهتر هم بشود.*

## ۸. محدودیت‌ها
* **دانش ازپیش‌آموخته ندارد.** فقط همان چیزی را می‌داند که به او بدهی؛ مترادفی که هرگز در داده‌ات ندیده را نمی‌شناسد.
* **فقط استخراجی.** نقل‌قول می‌کند، نمی‌نویسد. اگر متن روان لازم داری، با یک LLM (از طریق MCP) ترکیبش کن.
* آموزش با NumPy روی CPU است: تا چند صد هزار واژه برای هر مغز عالی است؛ میلیون‌ها سند نیاز به تقسیم دارد.
* گیت ابتدا از پرسش‌های ساختگی خودنظارتی یاد می‌گیرد — بازخورد واقعی خیلی بهترش می‌کند.
